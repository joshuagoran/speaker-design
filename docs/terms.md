# App terms

Each term has one meaning in the app. Check new UI text against this table.

| Term             | Meaning                                                                                                                                   |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Gain             | A level change in dB on a DSP output: an active band, a box in a Stack, or a placement in a Space.                                        |
| Pad              | A cut in dB on a passive band, in the box. It is 0 dB or less.                                                                            |
| System gain      | One gain in dB on all placements of a Space. It is 0 dB or less.                                                                          |
| Level            | A sound level in dB SPL that the app calculates.                                                                                          |
| Target level     | The level that the Space must get in the lowest band, at the Measured at location.                                                        |
| Band balance     | How the target changes above each crossover. Flat keeps it the same. More bass makes it lower.                                            |
| Measured at      | The location where the Space compares its level with the target.                                                                          |
| Listener         | The point in the room where the app calculates the listener level and the arrival times.                                                  |
| Main             | A placement that plays to the whole audience.                                                                                             |
| Fill             | A placement that plays to one area. It arrives after the nearest main, at that main's level.                                              |
| Calculate gains  | Sets the gains for a flat result. Speaker: the band gains and pads. Stack: the box gains. Space: the placement gains and the System gain. |
| Calculate delays | Sets each placement's delay. The mains arrive together at the listener. Each fill arrives after the nearest main.                         |
| Headroom         | How far in dB a box or band is below its limit.                                                                                           |
